# Planning & Collaboration Guidelines

## 1. When to Plan
* Plan thoroughly before undertaking multi-file refactors, introducing new dependencies, or integrating branches.
* When working with APIs, establish or verify the API contract (routes, request schemas, response shapes) before writing frontend or backend code.

## 2. Shared Team Documentation
* **`tasks.md`**: Update task statuses as items transition from `TODO` -> `IN PROGRESS` -> `COMPLETED`. Tag the active contributor.
* **`handoff.md`**: Maintain updated handoff notes summarizing what was built, what remains, and next priorities for pair collaborators.
* **`architecture.md`**: Update when data models, database schemas, or third-party service integrations change.
